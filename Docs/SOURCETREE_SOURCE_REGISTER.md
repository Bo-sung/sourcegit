# SourceTree 공식/보조 출처 등록부 (Source Register)

공유 문서: `Docs/SOURCETREE_FEATURE_INVENTORY.md` (기능 인벤토리, ST-xxx ID), `Docs/CORE_FEATURE_AUDIT.md` (포크 구현 상태, 다른 워커 소유)

## 0. 조사 방법과 접근 사실

- 모든 URL은 이 워커가 **2026-11-08**에 로컬 Python urllib(HTTPS, 일반 브라우저 UA)로 직접 GET해서 응답 코드와 본문을 확인했다. 계정·자격증명·설치는 쓰지 않았다.
- 페이지 발견(디스커버리)은 공식 사이트맵 `https://support.atlassian.com/sitemap.xml` → `https://support.atlassian.com/sourcetree/kb.xml` (S50) 목록 69건과 `https://support.atlassian.com/bitbucket-cloud.xml`를 파싱해 수행했다. 추측 URL은 등록하지 않았다.
- 접근 결과: 등록부 등재 페이지는 전부 HTTP 200. 예외 1건 — S49(커뮤니티 포럼)는 200이지만 본문이 JS 렌더링이라 정적 HTML에 답변 내용이 들어오지 않았다(본문 335자, 메뉴/푸터만). 해당 문장의 사실은 Lead가 확인해 준 인용에 의존했고, 그 사실을 행에 명시했다.
- 버전 기준: 이 프로젝트에 설치된 실측기준은 **Windows 3.4.32**. 공식 다운로드 아카이브(S05) 기준 **최신 공개 릴리스는 Windows/Enterprise 3.4.33 (2026-10-31)**. 제품 페이지(S01)의 "Release Notes" 링크는 3.4.32를 가리키므로 **마케팅 페이지 링크가 1개 릴리스 느림**. 인벤토리는 "3.4.32 확인 / 3.4.33 최신 참조"를 구분 표기한다.
- 공식 KB는 이전 사이트에서 옮겨졌고 페이지 하단에 "Updated on September 2x, 2025"를 표시한다. 이주 시점 갱신일이 3.4.32/3.4.33 UI와 1:1로 일치한다는 증거는 아니다(스크린샷은 특히 이전 버전일 수 있음). 또한 대부분 KB 하단에 "Platform Notice: Data Center Only / App: Sourcetree Data Center" 배너가 붙지만 본문 절차는 데스크톱 SourceTree 일반 절차이므로, 배너만 근거로 해당 기능을 Data Center 전용으로 분류하지 않았다(배너=사이트 이주 잔재로 취급, caveat 유지).
- Windows 3.4.x 근거에 macOS 4.x 릴리스 노트를 섞지 않았다. macOS/Mercurial 근거는 별도 라벨(D3/M)로만 사용.

근거 등급(인벤토리와 동일 정의): **D1** 현행 공식 문서 확인 · **D2** 공식 Windows 릴리스 노트에 버전 특정 · **H** 공식이지만 역사적 증거만 · **M** 타 플랫폼(Mac) 전용 증거 · **U** 1차 증거 없음(미확인 후보) · **S** 2차 근거(이슈 트래커/포럼)만.

## 4. 접근 실패 · 확인 못 한 것 (은폐하지 않음)

1. **S49 (community.atlassian.com)** — HTTP 200이지만 본문이 클라이언트 렌더링이라 정적 응답에 답변 텍스트가 없었다. 재시도(단일 URL)에도 동일. → 인용은 Lead 검증 요약에 의존, 등급 S.
2. **사이트맵 미등재 KB** — `support.atlassian.com/sourcetree/kb.xml` 외 섹션(`/sourcetree/get-started/`, `/sourcetree/docs/`)을 직접 요청하면 **HTTP 404**였다. 공식 KB 69건 외 get-started 문서 트리는 현존하지 않는 것으로 확인(추측 URL 미등재).
3. 스크린샷 이미지는 다운로드·시각 분석하지 않았다. UI 위치 서술은 KB 텍스트에 적힌 메뉴/버튼 이름만 근거로 했다. **어떤 항목에서도 "스크린샷에서 읽었다"는 근거를 쓰지 않는다** — 이미지 안에만 있는 정보는 "미확인"으로 남긴다(예: S16의 reset 대화 컨트롤).
4. Jira 검색 API로 기능 목록을 훑지 않았다. 이슈 트래커는 S48 1건(워크트리)만, 그리고 "기능 요청 = 출시 기능"으로 읽지 않도록 보조로만 사용.
5. 인증서 trust 관련 KB(resolving-ssl-self-signed-certificate-errors, manually-importing-root-code-signing-certificate-for-windows)에는 SourceTree 전용 UI 단계가 확인되지 않아 기능 행으로 등재하지 않고 인벤토리 간극(G13)에 기재했다.
