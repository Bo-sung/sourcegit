## 발견한 결함

- Windows Git의 `schannel: SEC_E_UNTRUSTED_ROOT`를 제품 TLS 오류 안내로 분류하지 못한다. 실제 로컬 자체 서명 인증서로 재현했고, fixture CA를 지정한 양성 대조에서는 TLS 연결을 통과했다. 이번 검증에서는 소스를 수정하지 않았다.
- 첫 GUI 패스의 설정 미적용은 테스트용 JSON 경로 이스케이프 오류였다. 유효 JSON 생성 및 실행 UI·설정 확인으로 재시도에서 해결했다. 제품 Classic 실행 실패로 분류하지 않는다.
